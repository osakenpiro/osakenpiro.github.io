HOW IT WORKS

掲載のものさし

  1. 運営元と公式URLが確かめられる。
  2. 実際に使える公開ページがある。
  3. 用途が短く説明できる。
  4. 自動確認で状態を更新する。
  5. 停止や終了も履歴として残す。
1回の通信失敗では消しません。3回連続の失敗で通常表示から外し、復旧後に戻します。
EDITORIAL NOTE

選ぶのは誰？

初版の収録範囲は、運営者本人が管理する公開サービスに限定しています。URLが存在することと、サービスの品質を推薦することは別の話です。

ロボットによるアクセス確認は、使えることを保証しません。終了の断定には運営者による明示的な根拠が必要です。

FUTURE CONNECTION

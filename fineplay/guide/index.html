QUICK START / FRIENDS PREVIEW v0.2

1分でわかる、
今日の遊び方。

Discordで話す。FINEPLAYで質問数と拍手を共有する。
まずは下の「ここだけ読めばOK」を読んだら、ひとまず一問。

別タブでゲームを開く ↗ここだけ読めばOK ↓
始める自分の操作得点と拍手困ったとき感想を伝える
01 / JUST ONE MINUTE

ここだけ読めばOK。

  1. Discordで通話をつなぐ。音声はいつものDiscord。FINEPLAYのマイク設定やBot追加は不要。
  2. 1人が部屋を作り、招待URLを送る。仲間はそのURLを開いて名前を入力。全員が同じ卓に入ったら開始。
  3. 出題者が答えを1つ決める。答えは頭か手元に。ゲームにはまだ入力しない。お題の範囲もみんなで確認。
  4. 質問者は「この質問をする」→ 声で質問。出題者は5択を押して回答。質問文の入力は空欄でもOK。
  5. わかったら「答えがわかった」。答えを入力して宣言し、出題者が判定。「いい質問！」には質問ログからFinePlay。
招待URLは、ゲーム内でコピーするもの。このマニュアルや紹介ページのURLだけでは、同じ卓には集まりません。部屋の 招待URLをコピー を使ってください。
02 / KNOW YOUR BUTTONS

自分は、何を押す？

部屋を作った人

名前を入れて 部屋をつくる。招待URLをコピー で仲間を誘います。2人以上が入室したら、出題者・お題の範囲・FinePlayの発表方法を選び、このメンバーで始める。

部屋を作った人と、出題者は別の役です。作成者は最初に出題者を選べて、次のお題でも交代できます。ただし部屋を支える役は変わりません。タブを開いたまま、端末も休止させないでください。

出題する人

答えを1つ決めて、質問を待ちます。質問が届くと、次の5択が出ます。

はいいいえたぶんそうたぶん違うわからない

無理に断定せず、わからないことは わからない で。解答宣言が来たら 正解！ または ちがいます。正解すると、答えが全員に表示されます。

質問する人

他の人の回答待ちでないときに この質問をする を押して、Discordで質問します。文章は任意。後から質問ログの メモ で名質問を残せます。

答えが浮かんだら 答えがわかった → 答えを入力 → この答えを宣言する。解答宣言も1問なので、当てずっぽうを続けるとスコアは増えます。

お題を交代する

終了後、部屋の作成者が 次のお題へ を押し、出題者や範囲を選び直します。新しいお題は0問から。部屋の招待URLはそのままです。

03 / SCORE & APPLAUSE

質問数と、FinePlay。

基本スコアは卓全体の質問数。少ないほどよい。回答が確定した質問と、判定された解答宣言を合計します。

操作数え方
5択で答えた質問（わからないも含む）1問
解答宣言（正解・不正解どちらも）1問
仲間内の相談、メモの編集0問
回答前に取り消した質問0問
FinePlayの拍手別記録

FinePlayは「いい質問」への拍手

質問ログで他の人の質問に ✦ FinePlay。1人1質問1票、自分の質問には投票できません。もう一度押すと取り消せます。解答宣言は拍手の対象外です。

「いい質問の数」と「拍手の票数」は別。1つの質問に3人が拍手しても、FinePlayが付いた質問は1問、拍手は3票。質問数から減点したり、合成得点にしたりはしません。

拍手を出すタイミング

その場で拍手：すぐ全員に表示。盛り上がり重視です。
答え合わせの後：進行中は他の人の票数を隠し、終了後に発表。出題者の「いい質問」がヒントになるのを避けたいときはこちら。

発表前も、部屋の作成者のブラウザには票が保持されます。厳密な秘密投票ではなく、仲間内の信頼を前提にしたモードです。

結果をDiscordに貼る

終了画面の Discord用の結果 でコピー。答えや質問文にはネタバレ用の記法が付きます。貼り付け内容を確認してから送信してください。自動投稿はしません。

04 / WHEN SOMETHING GOES SIDEWAYS

困ったときは。

「部屋が見つかりません」・つながらない

まず、部屋の作成者がゲームのタブを開き、オンラインになっているか確認。仲間にはゲーム内でコピーした招待URLを送ります。Discord内での表示がおかしいときは、端末の通常のブラウザで開いてみてください。

端末や回線によって接続できない場合があります。ブラウザの安全設定を弱めたり、認証情報を共有したりする必要はありません。何度試しても同じなら、下の試遊メモで状況を教えてください。

途中で止まった・作成者が再読み込みした

まず作成者の画面を確認。同じタブの再読み込みからの復帰を試みる実装ですが、全環境で確認済みではありません。接続表示を見て待ち、必要なら 再接続。復帰しない場合は、新しい卓を作り直してください。

作成者がタブを閉じたり、スマホが休止すると卓は停止します。ホストの自動交代や、閉じた卓の復元保証はありません。作成者はPC推奨です。

回答を押し間違えた

回答前なら 質問を取り消す で0問に。回答後は出題者が 直前の回答を訂正（正解後は 判定を訂正）を選びます。

訂正すると最後の1問が回答待ちに戻り、その質問のFinePlayは取り消されます。別の質問が回答待ちのときは訂正できません。降参して公開したあとにも戻せません。

誰も当てられない・終わりたい

回答待ちの質問を終えるか取り消したあと、出題者が 降参・お題を公開。答えを入力して終了します。この操作で質問数は増えません。

参加者名が使えない

名前は1〜24文字、同じ卓で重複しない名前に。最大12人です。退出した人も名簿に残るため、席や名前を整理したいときは新しい卓を作ってください。

05 / PLAY, NOTICE, IMPROVE

ひとことから、よくしよう。

よかった質問、面倒だった操作、止まったところ。いつものDiscordに、そのまま書いてくれればOK。不具合なら「何をしたら、どうなった」を添えてもらえると助かります。

友達への案内文 ↗

入力は送信されません。文章欄を選択してコピーし、Discordに貼ってください。PCは Ctrl+A → Ctrl+C、スマホは長押しで選択できます。招待URL、個人情報、未公開の答えはメモやスクリーンショットから除いてね。

RELEASE NOTE / 2026.09.21

今回のリリースについて。

Friends Preview v0.2。完成を待ち続けるより、仲間内で遊びながら改善していくための試遊公開です。

ゲーム本体は公開画面、部屋作成、オンライン表示、招待リンク発行まで確認済み。複数人での通しプレイ、異なる端末・回線での接続、復帰は検証中です。質問数とFinePlay、5択回答、出題者交代などを実装していますが、全環境の動作は保証していません。

参加リンクを知る人が入室できる仕組みです。名前・質問・回答・投票を卓の参加者間で扱い、接続にPeerJS等の外部サービスを利用します。本人認証、サーバー上の対戦履歴保存、ホスト移譲、音声録音、AIによる判定はありません。

紹介ページとマニュアルを追加しました。既存のゲームURLと部屋の招待リンクは変更していません。

## 通信・保存・情報の範囲

本番は2〜12人。PeerJS 1.5.5 / WebRTC の部屋作成者中心の接続です。PeerJS は必要時に jsDelivr から読み込みます。体験モードはこの通信ライブラリを読み込まず、部屋へ接続しません。

部屋の作成者のブラウザが状態と権限を管理します。出題者の交代は可能ですが、部屋を支える役の自動移譲はありません。作成者はPC推奨で、元のタブを開いたままにします。停止時は作成者の接続を確認し、参加者は元のタブで再接続します。実機の休止・閉じたタブの復元・別端末への引き継ぎは保証していません。

復帰用の進行・参加情報は `sessionStorage`、個人の仮説や音・表示の設定は `localStorage` に保持します。サーバー上のプレイ履歴、アカウント、端末をまたぐ通算保存はありません。保存できないブラウザ設定では保持できません。結果を残す場合は利用者自身がコピーします。

参加リンクを知る人は入室できます。本人認証・厳密な不正対策はありません。名前・質問・回答・コメント・評価などを、作成者が受け取り、遊び方と役割に応じて配信します。出題者の答え・未公開の属性や終了後発表の評価は他の参加者の画面には表示しませんが、状態を管理する作成者に対する秘密を保証するものではありません。

音声通話は Discord などで行います。FINEPLAY は音声を録音・文字起こししません。正誤は人が判定します。検索は利用者が外部ページを開く操作、AI相談は確認した公開情報をコピーして利用者自身がAIへ渡す操作です。AIへ自動送信・自動回答しません。

感想・不具合はゲーム内でメモをコピーし、紹介者へいつもの連絡手段で送る現行方式を維持します。架空のメールアドレス、送信フォーム、公開サポート窓口や対応保証は設けません。外部一般公開に向けた運営窓口・正式な利用条件は別途決定が必要です。素材の根拠と未確認事項は [provenance.md](provenance.md) を参照してください。

## 実装と検証の扱い

静的 HTML / CSS / JavaScript を既存の構成で維持します。現行 `index.html` が読み込む順序と拡張モジュールを確認して変更してください。`app.js` と `versions/` は旧版保全を含み、現行入口への再接続や無断削除をしません。画像・音はローカルのアセットを使用し、実行時の画像生成APIはありません。

公開 R6-motion の記録では、ローカル Chromium・母艦 Edge・公開URLのブラウザ確認、版のソース照合、R6 / R5 への復元照合が完了しています。記録と検証条件は [#381 の R6-motion RETURN](https://github.com/osakenpiro/claude-shared/issues/381#issuecomment-6096330933) を参照してください。その PASS を、この1.0候補の PASS として流用しません。

品質改善Aはローカルの独立QAと母艦Edgeで変更箇所を検証し、公開後の配信・操作も確認します。結果・実行環境・before/after・残課題は正本へ返します。ブラウザのスマホ幅での確認は実機スマホでの確認と区別します。実際の友人同士・異なる回線でのP2P、実機休止・実ネットワーク切断、登録通算や未実装のセッション機能を未検証のまま PASS としません。

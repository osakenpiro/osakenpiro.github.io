## 0.3で追加したもの
- 承認されたまじん・森の絵を実画面とLPへ。親指・人差し指・小指を立てたFinePlayの手のマーク。
- ひとり体験。架空メンバーのサンプル卓で出題側・質問側を切り替え、5択、履歴、メモ、FinePlay、結果を操作できます。AI対戦ではありません。
- ゲーム中もリザルトでも履歴を表示。PCは右側、スマホは下とジャンプリンク。検索、回答別フィルター、表示順、古い履歴を読んでいる間のスクロール位置保持。
- ゲーム内の感想・不具合メモと結果コピー。自動投稿・自動送信はしません。
- LPから実画面を開く導線と、実装に合わせたマニュアル。

## ルール
回答は、はい／いいえ／たぶんそう／たぶん違う／わからない。部分的な肯定を独立して表す選択肢は未実装です。

回答が確定した質問と、判定された解答宣言は各1問。解答宣言は正誤を問いません。回答前の取り消し・相談・メモ編集は0問。

FinePlayは質問数とは別の記録。通常質問に1人1票、自分の質問には付けられません。解答宣言は対象外。即時表示／終了後発表を選択できます。

質問文の入力は任意です。音声を録音・文字起こししないため、声だけの質問は本文未記録と表示。必要な内容は質問者か出題者がメモで補います。

## 通信・秘密・保存の範囲
本番は2〜12人。PeerJS 1.5.5 / WebRTCの部屋作成者中心の接続です。作成者のブラウザが状態・権限を管理し、PC推奨でタブを開いたままにします。出題者の交代はできても、部屋を支える役の自動移譲はありません。

参加リンクを知る人が入室できます。仲間だけに共有してください。本人認証・厳密な不正対策はありません。正解は開始時に入力せず出題者が手元に保持し、終了時に公開します。終了後発表の票は作成者のブラウザに保持されるため、厳密な秘密投票ではありません。

本番の同じタブからの復帰用情報はsessionStorageに保持します。閉じた卓の復元保証やサーバー上の履歴保存はありません。接続・中継サービスと回線状況に依存します。

体験モードはPeerJSを読み込まず、部屋の接続・参加・保存を行いません。架空メンバーを明示し、結果コピーにもサンプル表示を付けます。

## 実装ファイル
`index.html` → `engine.js` + `play.js` / `play.css`。
`engine.js`・protocol version 2・room namespace・sessionStorage prefixは維持しています。旧`app.js`は保全していますが、新しい入口からは読みません。

`home/`・`guide/`は`landing.css`を使用。画像は承認済み絵の切り出しをWebPとして埋め込んだ静的SVGで、生成APIは使用していません。

# FINEPLAY 0.2 — 人間同士の推理クイズ

遊ぶ入口: https://osakenpiro.github.io/fineplay/

Discord通話で質問しながら、各参加者が同じ卓の質問数・回答・FinePlayを見るWebアプリ。アカウント登録やDiscord Botの追加は不要。Akinator公式製品・API連携ではありません。

## 始める
1. 部屋の作成者が名前を入れて「部屋をつくる」。
2. 「招待URLをコピー」で得たリンクを仲間だけに共有。仲間も名前を入力して入室。
3. 作成者が出題者・お題の範囲・拍手の発表方法を選んで開始。

質問者が「この質問をする」を押して声で質問。文章は任意。出題者の5択回答で1問。解答宣言も正誤を問わず1問。FinePlayは別表彰で、他の人の質問に1人1票。取り消し・回答の訂正・出題者交代に対応するコードを実装しています。

## 通信と制約
- PeerJS 1.5.5 / WebRTC data channels。部屋作成者のブラウザが状態と操作権限を管理するスター型。
- 部屋作成者はタブを開いたままにしてください。PC推奨。タブを閉じたりスマホで休止すると卓が停止します。ホストの自動交代はありません。
- 参加者ごとに通信接続と参加IDを結び付け、操作の出題権限・自薦票・古い質問への回答をホストで検査します。身内向けのブラウザ単位の参加であり、公的な本人認証ではありません。
- 正解は開始時に入力させず、出題者が手元で保持します。終了時に公開します。終了後発表の投票は主催者のブラウザで保持されます。
- ブラウザ内の復帰情報にはsessionStorageを使用。接続サーバーと必要時の中継を使用します。回線依存があり、全環境の接続を保証しません。
- 録音、AIによる回答判定、独自の分析サービスへのゲーム履歴送信はありません。会話は別途Discordで行います。

## 検証範囲
`node test-engine.cjs` — ローカルで30/30 PASS。決定的なルール・権限・スコア・状態の投影の単体テストです。

公開ページの描画、部屋作成、オンライン表示、招待リンク発行は実ブラウザで確認済み。複数参加者による通しプレイ、異なる実機・回線、モバイル表示、再接続は完了確認前です。0.2は試遊版であり、単体テストの成功をオンライン実証と同一視しません。

QUICK START / FRIENDS PREVIEW

今日の遊び方。

誰かが決めた答えを、みんなの質問で当てる。いい質問にはFinePlay。通話はDiscordなど、質問・回答・拍手はこの画面で共有します。

質問する側を試す →答える側を試す →部屋をつくる →
始める履歴質問数とFinePlay困ったとき感想を伝える
01 / START A ROUND

仲間と、一卓。

  1. Discordなどで通話をつなぐ。FINEPLAY側のマイク設定やBot追加は不要です。
  2. 1人が名前を入れて、部屋をつくる。「招待URLをコピー」で仲間へ。参加者はそのリンクを開き、名前を入れて参加します。
  3. 作成者が、出題者・お題の範囲・FinePlayの発表方法を決めて開始。出題者は答えを1つ頭か手元に。開始時に正解を入力する必要はありません。
  4. 質問者が「この質問をする」を押し、声で聞く。文章も残したいときだけ質問メモを入力。出題者が5択で回答します。
  5. わかったら「答えがわかった」。解答を入力して宣言し、出題者が正誤判定します。いい質問には手のマークでFinePlay。
作成者はPC推奨。タブを開いたままに。作成者と出題者は別の役です。出題者を交代しても、卓を支えるブラウザは同じ。閉じたり端末が休止すると進行が止まります。集合に使うのは紹介ページではなく、部屋の招待URLです。

ひとりチュートリアル

質問役は練習用の質問を選んで送り、回答と履歴を見ながら答えを宣言。台本の相手が答えるので、自分で回答役へ切り替える必要はありません。答えがわからないときは画面内のヒントを開けます。

魔人役は、お題「傘」について順に届く質問へ5択で回答。最後の解答宣言を判定すると結果へ進みます。台本は決まった順番で進みます。

どちらも「最初から」でやり直せます。結果から、もう一方の役を試すか、本番の部屋をつくれます。練習はこの端末だけ。本番は人が声で自由に質問し、人が答えます。AI対戦でも、オンライン接続テストでもありません。

役を切り替えて自由に操作するのは、セルフチェック用の別モードです。

02 / KEEP THE CLUES

前の質問も、見返せる。

回答すると「ここまでの質問」に、質問番号・メモ・回答・質問した人・FinePlayの印が並びます。ゲーム中も結果でも参照でき、スマホでは「履歴 ↓」から移動できます。

「履歴を探す」で質問文・回答・名前を検索し、回答別に絞り込めます。古い順／新しい順も切り替えられます。履歴の行を開くと、FinePlayとメモの操作が出ます。

音声の録音・文字起こしはしません。声だけの質問は本文未記録と表示されます。質問者か出題者が「メモを直す」で補えます。

次のお題へ進むと、表示する質問履歴は新しくなります。残したい結果は、先に「Discord用の結果」で確認してコピーしてください。サーバー上の履歴保存や、閉じた卓の復元保証はありません。

03 / SCORE & FINEPLAY

少ない質問で、いい切り口を。

スコアは卓全体の質問＋解答宣言の数。回答や正誤が確定した時点で1問と数えます。

○ はい× いいえ△ たぶんそう◇ たぶん違う？ わからない

「たぶん」は確信度です。「部分的にはい」という意味の回答は別に用意していません。

操作数え方
5択で回答（わからないも含む）1問
解答宣言への判定（正解も不正解も）1問
回答前の取り消し・相談・メモ編集0問
FinePlay別記録

「それ、いい質問！」に拍手。

親指・人差し指・小指を立てた手のマークが目印。回答済みの質問カードや、履歴の行を開いたところから合図できます。ほかの人の質問に1人1票。自分の質問や解答宣言には付けられません。押し直すと取り消せます。

1つの質問に3人が合図すると、いい質問は1問・得票は3票です。質問数から減点したり、合算したスコアにはしません。

拍手を後から発表する

開始前に「答え合わせの後」を選ぶと、他の人の票数は終了後に表示されます。自分の投票操作は確認できます。作成者のブラウザは票を保持するため、厳密な秘密投票ではありません。

04 / SMALL TROUBLES

困ったときは。

部屋に入れない・途中で止まった

作成者が元のタブでオンラインか、端末が休止していないか確認します。紹介ページではなく「招待URLをコピー」で得た部屋のリンクを使ってください。必要なら通常のブラウザで開き、「再接続」を試します。

回線によっては接続できないことがあります。安全設定を弱めたり、認証情報を共有する必要はありません。作成者の自動交代や、閉じた卓の復元保証はありません。

回答を押し間違えた

出題者が「訂正・その他」から「直前の回答を訂正」（正解後は「判定を訂正」）を選びます。最後の1問が回答待ちに戻り、その質問へのFinePlayは取り消されます。別の質問が回答待ちのときや、降参後は戻せません。

当たらないので終わりたい

出題者が「訂正・その他」→「降参・お題を公開」で答えを入力して終了します。質問数は増えません。作成者が「次のお題へ」を選ぶと出題者を交代できます。

名前が使えない

名前は1〜24文字、重複なし、1卓12人まで。退出者も名簿に残るため、名簿を整理したいときは新しい卓をつくってください。

05 / DEBUG WITH FRIENDS

ひとことから、よくしよう。

ゲームの「感想・不具合」で試遊メモをコピーし、紹介してくれた人へ。自動送信はしません。端末・何をしたか・どうなったかを添えると確認しやすくなります。

招待URLや個人情報、まだ公開していない答えは書かないでね。招待リンクを知る人は入室できます。リンクは仲間だけに送りましょう。

試遊版としての範囲

ひとり体験の動作と、実際の友達同士の接続・異なる端末や回線での対戦は別に確認しています。本人認証・厳密な不正対策・音声録音・AIによる回答判定・回答画像の自動生成はありません。

名前・質問・回答・投票は参加者間で共有し、接続にPeerJSなどの外部サービスを使用します。
